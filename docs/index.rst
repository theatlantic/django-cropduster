Documentation
=============

django-cropduster provides a drop-in replacement for Django's ``ImageField`` that can generate multiple crops at predefined sizes and aspect ratios. It was created by developers at `The Atlantic <http://www.theatlantic.com/>`_.

Compatibility
=============

django-cropduster requires Python 3.10+ and supports Django 4.2, 5.0, 5.1 and 5.2. It depends on django-generic-plus 4.x.
